# Architecture

KOKUEN is a portable design-system package. `SKILL.md` directs AI work, `docs/CUSTOM_THEME.md`
defines product-specific direction, `tokens/kokuen.tokens.json` stores DTCG-aligned foundation data,
`reference.md` records the component/interaction contract, `kokuen.css` supplies foundation styles,
and `preview.html` exercises a representative real surface. `scripts/validate_theme.py` validates
token objects and aliases without third-party dependencies. Current website and Alles code outrank
snapshots in this repository.
