# Components

The initial KOKUEN surface is documented in `reference.md`: buttons, fields, custom controls, list rows, command dialog, dialog, toast, status marks, loading/empty/error patterns, and tokenized foundations. The command dialog is the first global composition and defines focus and keyboard behavior for future command/search work. `docs/CUSTOM_THEME.md` requires components to consume semantic or component tokens rather than raw values, and to be proved under an error/dense-content/overlay stress set before being considered reusable.
